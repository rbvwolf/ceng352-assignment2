# CENG352 - Software Verification and Validation course, Assignment 2 
## Automated Unit Tests using Github Actions
In this project, we developed a custom login system using HTML, CSS, and JavaScript. The system includes input fields for first name, last name, email, password, and password confirmation.

To ensure the correctness and reliability of the system, we implemented a total of 26 automated unit tests. These tests focus on validating user inputs and checking various edge cases, such as:

Empty input fields
Invalid email formats
Password strength requirements
Password and confirmation match validation

All tests were integrated into a continuous integration (CI) pipeline using GitHub Actions. The test suite runs automatically on each update to the repository, ensuring that any new changes do not break existing functionality.

All 26 tests passed successfully, indicating that the login system behaves as expected under the tested conditions.

This project demonstrates the importance of automated testing in maintaining software quality, especially for user authentication systems.
